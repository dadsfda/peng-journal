# 单屏沉浸式主页设计

## 目标

将当前主页改为仅包含一个沉浸式 Hero 的单屏封面。页面在常见桌面端和移动端视口中不产生纵向滚动，同时保留固定顶部导航，让访客可以继续进入博客其他页面。

## 视觉方向

背景使用用户提供的暖色安静工作台照片，作为项目本地静态资源保存。画面包含正在编程的人物、电脑、笔记本、书籍、植物、柔和夕阳和中文墙面装饰。整体保留现有纸张感与衬线字体，并用深色遮罩平衡照片的暖橙色调。

Hero 在照片上叠加从左深右浅的黑灰遮罩，左侧窗户与桌面区域作为文字承载区。标题位于左下区域，使用白色衬线大字；眉题和介绍文案使用较低对比度的暖白色。背景图片加载失败时，以深暖灰纯色作为兜底，保证文字仍可读。

## 页面结构

- 保留全站固定顶部导航。
- 主页主体仅渲染 Hero，不再渲染 GitHub Trending、精选文章或继续阅读。
- 不删除上述组件或相关数据逻辑，其他页面和路由保持不变。
- Hero 提供“阅读文章”和“关于我”两个入口，分别链接到 `/posts` 和 `/about`。

## 布局与响应式

主页通过专用 class 标识单屏布局。主体高度使用视口高度减去导航实际占用空间的方式计算，并限制溢出，避免纵向滚动。桌面端文字位于左下方；移动端调整背景裁切焦点、缩小标题并将操作入口纵向排列。

全局其他页面继续使用现有主体和页脚布局。主页不显示页脚，以确保单屏高度可控。

## 验证

- 主页构建产物只包含 Hero，不包含 Trending、精选文章和继续阅读。
- Hero 包含两个可访问的导航入口和本地背景图片。
- 单屏布局样式包含视口高度约束、溢出控制、遮罩和响应式规则。
- 运行完整 Vitest、Astro 检查和生产构建。
- 使用真实浏览器分别验证桌面和移动视口下 `scrollHeight <= innerHeight`，并检查主要文字和链接可见。
