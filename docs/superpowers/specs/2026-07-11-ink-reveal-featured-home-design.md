# 水墨擦除与随机精选主页设计

## 目标

在现有单屏主页上，将博客名改为居中展示，并在下方显示每次打开或刷新页面时随机选择的一篇精选文章。背景照片上覆盖与页面背景同色的 Canvas 遮罩，鼠标移动时以水墨扩散效果擦开遮罩，短时间后自然恢复。

## 页面层级

从底到顶依次为背景照片、Canvas 遮罩、居中内容。居中内容始终位于 Canvas 上方且不受擦除影响，顺序为眉题、博客名、简介与随机精选文章入口。移除现有“阅读文章”和“关于我”按钮，顶部导航继续承担全站入口。

## 随机精选文章

主页构建时读取所有已发布且 `featured: true` 的文章，将标题、描述和永久链接传给 Hero。浏览器在首次加载时用 `Math.random()` 选择一篇，因此每次刷新可能显示不同文章。服务端输出第一篇作为无 JavaScript 回退；如果没有精选文章，则不显示精选入口。

精选入口使用“本次精选”标签、文章标题和阅读箭头组成，位于简介下方。整个区域为一个可聚焦链接。

## WebGL 流体水墨遮罩

遮罩参考 `webgl-splash-cursor` 技能提供的 `SplashCursor.jsx`，使用 WebGL framebuffer、速度场、压强、涡旋、平流和 dye 纹理实现真正的流体扩散。项目保持 Astro 架构，不引入 React；将参考组件的 WebGL 核心迁移为原生浏览器模块。

采用参考模式参数：`SPLAT_RADIUS=0.5`、`SPLAT_FORCE=6000`、`DENSITY_DISSIPATION=1.8`、`VELOCITY_DISSIPATION=1.35`、`PRESSURE=0.8`、`PRESSURE_ITERATIONS=25`、`CURL=30`，并保留鼠标 delta 的十倍放大。关闭 DPR 采样，流体纹理使用半尺寸分辨率，获得更大、更柔和的扩散边缘。

修改参考实现的显示 shader：没有流体的位置输出与页面背景相同的暖灰色不透明遮罩，dye 浓度越高的区域透明度越低，从而露出下方照片；dye 随时间消散后遮罩重新恢复。Canvas 绝对定位在背景与内容之间，并保持 `pointer-events: none`。

如果 WebGL、浮点纹理或必要 framebuffer 不可用，则回退到当前 2D Canvas 粒子擦除逻辑，避免主页失效。

## 响应式与无障碍

移动端与不支持精确鼠标的设备不启用 WebGL 流体动画，改用半透明静态遮罩，让背景照片可见。用户启用 `prefers-reduced-motion` 时采用相同静态降级。Canvas 本身标记为装饰性，不进入无障碍树。

主页继续保持 `100dvh` 单屏且无纵向滚动。居中标题在桌面端保持强视觉焦点，移动端允许自然换行并缩小精选入口。

## 验证

- 组件测试验证精选文章数据与 Canvas 挂载点输出。
- 页面源码测试验证随机选择、WebGL context、framebuffer、流体 shader、参考参数、2D 回退与降级媒体查询。
- 完整 Vitest、Astro 检查与生产构建通过。
- 浏览器验证桌面端使用 WebGL，鼠标移动后出现大面积卷曲透明区域并随 dye 消散恢复；同时验证强制关闭 WebGL 时 2D 回退仍可工作。移动端保持无纵向滚动，标题和精选入口可见。
