# 水墨擦除与随机精选主页设计

## 目标

在现有单屏主页上，将博客名改为居中展示，并在下方显示每次打开或刷新页面时随机选择的一篇精选文章。背景照片上覆盖与页面背景同色的 Canvas 遮罩，鼠标移动时以水墨扩散效果擦开遮罩，短时间后自然恢复。

## 页面层级

从底到顶依次为背景照片、Canvas 遮罩、居中内容。居中内容始终位于 Canvas 上方且不受擦除影响，顺序为眉题、博客名、简介与随机精选文章入口。移除现有“阅读文章”和“关于我”按钮，顶部导航继续承担全站入口。

## 随机精选文章

主页构建时读取所有已发布且 `featured: true` 的文章，将标题、描述和永久链接传给 Hero。浏览器在首次加载时用 `Math.random()` 选择一篇，因此每次刷新可能显示不同文章。服务端输出第一篇作为无 JavaScript 回退；如果没有精选文章，则不显示精选入口。

精选入口使用“本次精选”标签、文章标题和阅读箭头组成，位于简介下方。整个区域为一个可聚焦链接。

## Canvas 水墨遮罩

Canvas 绝对定位在背景图与内容之间，尺寸根据元素边界和设备像素比同步。每帧先用与页面背景相同的暖灰色重绘完整遮罩，再使用 `destination-out` 绘制仍处于生命周期内的墨迹粒子。

鼠标在 Hero 内移动时，以有限采样频率创建粒子组。每组包含大小、位置、旋转和透明度随机的椭圆与圆形墨迹，并使用径向渐变产生柔和边缘。粒子在约 1.5–2.5 秒生命周期内先快速扩散，再逐渐降低擦除强度，使遮罩自然恢复。限制最大粒子数量，并通过 `requestAnimationFrame` 驱动动画。

鼠标离开 Hero 后不再生成粒子，已有粒子按生命周期恢复。Canvas 设为 `pointer-events: none`，不影响链接操作。

## 响应式与无障碍

移动端与不支持精确鼠标的设备不启用跟手粒子动画，改用半透明静态遮罩，让背景照片可见。用户启用 `prefers-reduced-motion` 时采用相同静态降级。Canvas 本身标记为装饰性，不进入无障碍树。

主页继续保持 `100dvh` 单屏且无纵向滚动。居中标题在桌面端保持强视觉焦点，移动端允许自然换行并缩小精选入口。

## 验证

- 组件测试验证精选文章数据与 Canvas 挂载点输出。
- 页面源码测试验证随机选择、Canvas 合成模式、粒子生命周期、动画帧与降级媒体查询。
- 完整 Vitest、Astro 检查与生产构建通过。
- 浏览器验证桌面端鼠标移动后 Canvas 出现透明区域并在生命周期结束后恢复；移动端保持无纵向滚动，标题和精选入口可见。
