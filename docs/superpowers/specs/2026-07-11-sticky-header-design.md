# 顶部导航吸附设计

## 目标

页面滚动后，顶部导航栏保持在视口顶部可见，同时保留现有桌面端和移动端布局，不遮挡正文。

## 方案

在现有 `.site-header` 上使用 CSS `position: sticky` 和 `top: 0`。导航仍处于文档流中，因此无需为正文增加占位高度。设置足够的 `z-index`，并使用与站点背景协调的半透明背景及 `backdrop-filter`，避免滚动内容影响导航文字可读性。

不引入 JavaScript，不修改 Astro 组件结构，也不改变导航链接或响应式排列方式。

## 验收标准

- 页面滚动时，导航栏吸附在视口顶部。
- 导航栏位于正文内容上方，文字清晰可读。
- 页面初始位置及移动端换行布局保持正常。
- 项目现有自动化测试、Astro 检查和构建通过。

## 验证

添加针对全局样式的回归测试，断言导航栏包含吸附定位、顶部偏移及层级规则。随后运行完整测试、`astro check` 和生产构建。
